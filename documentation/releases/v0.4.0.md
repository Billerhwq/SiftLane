# Siftlane v0.4.0

## Added

- Managed wheel install, enable, disable, upgrade, rollback and uninstall with SHA-256 verification and isolated child-process execution.
- A real JSON Feed 1.0/1.1 reference connector.
- Fernet-encrypted connector and delivery-target secrets with metadata-only APIs.
- NDJSON and signed or authenticated Webhook delivery.
- Target-level idempotency, bounded exponential retry, dead-letter history, cancellation and authorized replay.
- A permission-aware integration control plane for connectors, secrets, targets and delivery history.

## Required Action

Team deployments must set `SIFTLANE_ENGINE_SECRET_KEY` to a stable value of at least 32 characters. Losing or changing this value makes stored secrets undecryptable. Back up the key through the deployment secret manager; never put it in the repository or browser environment.

## Compatibility

The engine accepts Connector SDK API `siftlane.connector/v1`. An incompatible manifest fails before the active connector record is changed. Existing P2/P3 flow, run and schedule data migrates additively.

## Rollback

Disable or roll back a connector independently. Pause a failing delivery target and replay its dead letters after repair. Before rolling the engine back, stop writers and preserve the complete SQLite data directory and the matching engine secret key.
