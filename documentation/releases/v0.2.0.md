# Siftlane v0.2.0

This release turns Siftlane's crawler workflow editor into a durable P2 control
plane with explicit routing, bounded expansion, recovery, and scheduling.

## New Features

- **Explicit branches**: Condition nodes route records through visible `true` and
  `false` ports, so operators can inspect and edit each path on the canvas.
- **Bounded loops and pagination**: Workflows can repeat controlled work without
  introducing graph cycles or unbounded execution.
- **Retry controls**: Transient node failures can use a bounded exponential retry
  policy, and exhausted attempts remain visible in run evidence.
- **Checkpoint recovery**: Completed node output is checksummed and restored after
  an engine restart, reducing repeated work while keeping results duplicate-free.
- **Timezone-aware schedules**: Operators can create, edit, pause, delete, and
  manually trigger cron schedules from the control plane.

## Improvements

- **One acceptance command**: Backend tests, the production Web build, and all P1/P2
  browser tests now run through one isolated root command.
- **Repeatable browser tests**: Each end-to-end run owns its engine, fixture server,
  Vite process, and SQLite directory, then releases all three ports.
- **Release integrity**: The release includes version-checked Python and Web
  artifacts, a machine-readable manifest, and SHA-256 checksums.

## Bug Fixes

- Fixed local configuration drift by using engine port `8090` consistently.
- Removed machine-specific drive paths from browser and recovery tests.
- Stabilized restart recovery verification by polling durable SQLite state instead
  of competing with the recovering service over HTTP.

## Breaking Changes

- **Action required**: Local development now requires Node.js 20.19+ or 22.12+.
- **Action required**: Custom local configurations that still use the old engine
  port must point the Web client and engine to port `8090`, or explicitly set both
  sides to the same alternative port.

No database migration is required for this release.
